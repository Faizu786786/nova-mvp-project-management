## ⚡ Key Highlights of Deliverables

### 1. Master Excel Project Plan (`.xlsx`) & Markdown Plan
* **Spreadsheet Generation**: Generated via `scripts/generate_excel_plan.py` using `openpyxl`. Contains 6 color-coded worksheets: *Summary, Backlog, Sprint Plan, Gantt Schedule, Risk Register, and RACI Matrix*.
* **Scoring Methodology**: Features MoSCoW prioritization and RICE scoring ($\text{Score} = \frac{\text{Reach} \times \text{Impact} \times \text{Confidence}}{\text{Effort}}$).

### 2. Interactive HTML Dashboard & Web Prototype
* **Dashboard (`dashboard.html`)**: Features real-time metric counters, Sprint velocity bar chart, risk impact matrix, EVM financial metrics, and interactive filters.
* **App Prototype (`nova_app_demo.html`)**: Demonstrates NOVA's task board, Kanban workflow, AI task recommendation engine, and notifications.

### 3. Change Request Analysis (CR-001)
* Analyzes mid-project scope addition request for "AI Task Recommendations".
* Evaluates 4 strategic options (Full Scope, Defer, Outsource, Hybrid MVP) across 6 impact dimensions.
* Recommends a **Hybrid Phased MVP** that safeguards the 10-week launch deadline while fulfilling AI capabilities.

### 4. Automated Python Script Engine
* [`generate_excel_plan.py`](NOVA_MVP_Submission/scripts/generate_excel_plan.py): Re-generates `NOVA_MVP_Master_Project_Plan.xlsx` from Python code with custom formatting and formulas.
* [`generate_pptx_deck.py`](NOVA_MVP_Submission/scripts/generate_pptx_deck.py): Re-generates `NOVA_MVP_Project_Management_Presentation.pptx` using `python-pptx` with sleek dark theme styling.
